# CSS Snippets

A collection of CSS snippets for customizing **Discord, BetterDiscord, and Vencord**.

These snippets focus on practical UI changes — cleaning up Discord's interface, improving existing elements, and restoring or modifying useful UI components.

## Snippets

| Snippet           | Description                                                                      |
| ----------------- | -------------------------------------------------------------------------------- |
| **Declutter**     | Removes visual clutter and unnecessary Discord UI elements.                      |
| **Enhancer**      | Improves and refines various Discord interface elements.                         |
| **SettingsIcons** | Backup version of the SettingsIcons theme.                                       |
| **quickCSS**      | A collection of quick CSS customizations originally based on Vencord's quickCSS. |
