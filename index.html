INSTALL

Get started in a few steps.

Every snippet is distributed as an external CSS import. Copy the import from the library, then add it to your CSS client.

01

BetterDiscord

  1. Open BetterDiscord Settings.
  2. Open Custom CSS.
  3. Paste the snippet's @import line.
  4. Save or apply your changes.
02

Vencord

  1. Open Vencord Settings.
  2. Open your custom CSS configuration.
  3. Paste the snippet's @import line.
  4. Save or apply your changes.
HOW IT WORKS

Use the website as the source for the imports rather than downloading the individual CSS files.

01

Choose a snippet

Browse the collection and find the customization you want.

02

Copy the import

Use the Copy button on the snippet card.

03

Paste it into your client

Add the import to your custom CSS configuration.

04

Apply your changes

Reload or apply the CSS and you're done.

Tip

The imports point to the maintained files hosted through GitHub Pages. You don't need to download or manually maintain the CSS files yourself.
